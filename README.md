# GEN_MEDICAL_SHEET

Create a virtual environment:

python -m venv venv

Activate the environment:

source venv/bin/activate

Deactivate the env:

deactivate

Install dependencies:

pip install -r requirements.txt

Run as a server: 

ollama serve
